Kalshi Line Monitor

A rule-based layer on top of the Predictive Markets setup board. It pulls each market's Kalshi ladder, grades every line, watches what you hold, and rolls the whole book up at the end. Every state comes from an ordered list of IF/THEN rules, so the same inputs always give the same answer. Position sizing is out of scope; where a rule needs a size threshold, it names a parameter your sizing work will fill.

Checked today, Nov 11: the signed Kalshi API reads the balance, all open positions (14 lines across 7 events) and live ladders. Exposure figures below come from that read. Odds, edges and flags in the mockups are illustrative.

The rules

Each layer is evaluated top to bottom and stops at the first rule that matches. Thresholds in CAPS are named parameters kept in the universe catalog, so changing a number never means changing code.

1 · Market gateper market · when an input publishes
# direction (your existing setup rule, unchanged)
IF   price outside Risk Range            THEN NONE  "outside range"
IF   Tick=Bull AND Trend=Bull
     AND price in bottom third
     AND NOT Trade=Bear                    THEN LONG
IF   Tick=Bear AND Trend=Bear
     AND price in top third
     AND NOT Trade=Bull                    THEN SHORT
ELSE                                     NONE  + the failing input

# grade (how many confirmations line up)
IF   setup AND Trade agrees AND price in outer EDGE_BAND   THEN A
IF   setup AND (Trade agrees OR price in EDGE_BAND)  THEN B
IF   setup                                       THEN C

NONE hides the market's lines and prints the reason ("Tick Neutral"). The grade is a label for monitoring; your sizing work can use it or ignore it.

2 · Line rulesper line · every quote pull
side   = YES if LONG, NO if SHORT
ask    = that side's quoted ask
ours   = calibration_curve(YES mid) # your existing curve
edge   = ours − ask − fee                 # in points

IF   one side unquoted OR spread > MAX_SPREAD  THEN ILLIQUID
IF   edge ≥ STRONG_EDGE  (5)                 THEN STRONG
IF   edge ≥ GOOD_EDGE    (3)                 THEN GOOD
IF   edge ≥ WATCH_EDGE   (1)                 THEN WATCH
ELSE                                         PASS

FLASH IF line becomes STRONG this pull AND not held

"Odds we like" means edge, so an 85¢ favourite and a 20¢ long shot are ranked on the same scale. Lines sort by edge, best first; PASS lines fold behind a count.

3 · Held rulesper owned line · every quote pull
IF   gate now points against held side      THEN CONTRADICTS  red
IF   price is through the line (held side
     currently losing)                       THEN THROUGH LINE yellow
IF   exit edge < 0  (ours < held-side bid)  THEN EDGE GONE    yellow
IF   gate is NONE (setup lapsed, not flipped) THEN SETUP LAPSED yellow
IF   closes within CLOSING_WINDOW (2h)      THEN CLOSING      blue
ELSE                                         HOLD

FLASH IF state turns CONTRADICTS

Every state carries a one-line reason ("Tick flipped Bullish 10:42"). Distance from the line is shown in the ladder's own σ, so a 3¢ move in copper and a $400 move in Bitcoin read the same way.

4 · Book ruleswhole account · every pull
at_risk  = Σ cost of open lines           # bought contracts: max loss = cost
account  = cash + position value

IF   at_risk / account > BOOK_CAP          THEN flag OVER BOOK CAP
IF   section at_risk > SECTION_CAP         THEN flag that section
IF   one expiry holds > EXPIRY_SHARE of risk THEN flag EXPIRY CLUSTER
IF   ≥2 held markets in a section, same direction,
     and their correlation > STACK_CORR     THEN flag STACKED
IF   any line is CONTRADICTS                THEN book header turns red

The caps are placeholders for your sizing work. Until they're set, the summary shows the numbers with no flags.

Colors and flashing

These follow the Inbox rules you already use. Red only when something contradicts a position you hold. Yellow for a signal: a new STRONG line, or a held line that has gone wrong. Blue for something to act on that isn't a problem, such as a line closing soon. Two things flash: a line that just became STRONG and isn't held, and a held line that just turned CONTRADICTS. A flash stops once you open the row, and the color stays. Each of these also lands in the Inbox as a card, with Source pointing at the Kalshi market and the publication that moved the gate.

Open decisions

Edge tiers. 1 / 3 / 5 points is a starting guess. The paper ledger can tell us which tier actually paid once it has a few weeks of tickets.
EDGE_BAND for grade A. Outer 10% of the Risk Range, or the outer half of the third?
Pull cadence. Every 60 s while any held event is open, every 5 min otherwise. The gate only re-runs when a Hedgeye input publishes.
Where it lives. Lines inside each section of the Predictive Markets report, with the book summary as the last block. Held rules also run in the background so the Inbox gets a card without the report open.
