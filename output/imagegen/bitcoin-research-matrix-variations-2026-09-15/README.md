# Analytical Bitcoin Research variations

Three static image concepts generated with the built-in image_gen tool, using the user's selected concept 03 and the running main dashboard as references.

A — Compact cross-table. Closest to concept 03: USD rows against volatility column groups, with percentage and sample count adjacent.
B — Bullish and bearish. Two aligned cross-tables preserve simultaneous comparison of the existing preferred entry rules.
C — Statistical table. Each USD/volatility combination occupies a row, exposing both close directions, change and counts.

Style follows the main dashboard's DM Sans typography, normal numerical values, light gray headers, ruled grids, square geometry and compact spacing. No product code changed. Generated image proportions are design previews, not exact CSS specifications.

Every percentage, sample count and confidence interval in these images is illustrative, not a calculated or verified backtest. No new volatility classifications or historical results were computed.

Prompts are preserved in prompts.md. Final images are the three lettered PNG files in this folder.
